# KPI Framework (potential measurement framework)

Illustrative only; no figures are targets or forecasts.

| Group | Example measures |
|---|---|
| Fan | Offer redemption rate, opt-in rate, fatigue incidents |
| Venue | Queue time delta, concession transactions, staffing response time |
| Sponsor | Engagement, activation revenue, rights compliance |
| Content | Audience reach, personalization rate, rights clearance time |
| Operating | Decisions per game, policy block/review rate, human override rate |

Method: establish a baseline, run a controlled comparison (matched games or zones), attribute incremental impact, and review with finance before any claim is made. The Business Outcomes page is an editable scenario calculator for this purpose.
