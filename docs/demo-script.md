# Demo Script (5 minutes)

1. **Open – Command Center (45s).** "This is a live game night. Signals stream in from fans, venue, sponsors and content. Every decision you see is made by an agent, checked against policy, and logged."
2. **SportsIQ Brain (45s).** "One shared intelligence layer. Five domains, one memory, one policy engine."
3. **Trigger the master scenario (90s).** Click *Trigger scenario*. Walk the steps: a signal appears, context is joined across domains, the Orchestrator reasons, policy checks run (consent, fatigue, rights, human review), actions fire, results count up, and four memories are written.
4. **Explainability (45s).** Open Agent Activity and a decision trace: SIGNAL → CONTEXT → REASONING → POLICY → ACTION → RESULT.
5. **Business Outcomes (45s).** Adjust the illustrative inputs. "This is a scenario calculator, not a forecast."
6. **Architecture (30s).** Microsoft-aligned view: data, agents, policy, memory, experience.
7. **Close.** "SportsIQ is the intelligence behind the experience. Now let's look at what that intelligence becomes in the hands of the fan."
